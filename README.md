# 🔋 EV Battery Thermal Management System

An electric vehicle (EV) battery thermal management system designed using MATLAB/Simulink to maintain battery temperature within safe operating limits for improved safety, efficiency, and battery lifespan.

The system dynamically controls heating and cooling operations using closed-loop thermal control logic and multi-state operating behavior.

---

## 🚀 Features

- Real-time battery temperature monitoring
- Cooling and heating control logic
- Overheating protection system
- Multi-state thermal management
- Closed-loop temperature regulation
- Stable thermal behavior under varying conditions
- EV-oriented safety control

---

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| MATLAB | System Modeling |
| Simulink | Dynamic Simulation |
| Stateflow | Multi-State Control Logic |

---

## ⚙️ System Working

1. Battery temperature is continuously monitored.
2. Control logic determines current thermal state.
3. Cooling or heating systems activate dynamically.
4. Temperature is maintained within optimal operating range.
5. Protection mechanisms prevent overheating conditions.

---

## 🔄 Thermal Control States

| State | Function |
|---|---|
| Cooling | Reduces battery temperature |
| Idle | Maintains stable condition |
| Heating | Raises low battery temperature |
