# Battery Thermal Management System (EV BMS Logic)

## Overview
Developed a battery thermal management system for electric vehicles using MATLAB/Simulink to maintain battery temperature within safe operating limits.

## Features
- Temperature monitoring and control
- Cooling and heating logic
- Protection against overheating
- Multi-state system behavior

## Technologies Used
- MATLAB
- Simulink
- Stateflow (if used)

## Working
- Battery temperature is continuously monitored
- Control system activates cooling or heating based on temperature range
- Maintains optimal operating temperature for safety and efficiency

## Control Strategy
- Closed-loop control system
- Multi-state logic (Cooling / Idle / Heating)
- Ensures stable temperature range

## Output
- Temperature vs time graph
- Stable thermal behavior under varying conditions
- System response to overheating scenarios

## Applications
- Electric Vehicle Battery Management Systems
- Thermal control in energy storage systems
